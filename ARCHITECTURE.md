# MSLM Architecture

## Overview
This document outlines the architecture for the Context-Aware Multi-cell Emergent Language Model (CAMEL) based on the MSLM (Multi Small Language Models) design.

## Core Components
- **CAMEL Cell:** A Tiny Transformer specialized in a single domain.
- **Biological Router:** Routes input using a Thalamus, Prefrontal Cortex, and Hippocampus hierarchy.
- **CAMEL Network:** Connects cells via learned relationships and spreading activation.
